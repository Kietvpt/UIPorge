# Dictionary: Aevum Ubiquitous Language

| Term | Definition |
| :--- | :--- |
| **Domain** | Một mảng nghiệp vụ lớn trong dự án (ví dụ: Auth, UI, Backend). |
| **Feature** | Một tính năng cụ thể thuộc Domain (sub-domain). |
| **Plan** | Kế hoạch thực thi chi tiết dưới dạng Markdown. |
| **Research Domain (Sphere)** | Không gian nghiên cứu khoa học cấp cao trong kiến trúc RDD. |
| **Research Topic (DAG Node)** | Một đề tài / giả thuyết nghiên cứu được phân nhánh trên đồ thị DAG. |
| **Universal Concept Engine** | Hạt nhân nhận dạng ý niệm ngữ nghĩa đa ngữ độc lập ngôn ngữ. |
| **STEB Engine** | Session-Adaptive Telemetry Budgeting điều phối 5 vùng ngân sách theo EMA. |
| **Zone E (Elastic Float)** | Quỹ dự phòng token 20% co giãn theo nhu cầu và hoàn trả thặng dư (Surplus Yield). |
| **Tree Knapsack Optimizer** | Thuật toán giải bài toán balo trên cây DAG có ràng buộc phụ thuộc cha-con. |
