# Aevum Research Library

Đây là không gian lưu trữ các báo cáo nghiên cứu, phân tích kiến trúc và tài liệu chuyên sâu của dự án do Agent tự đọc và đúc kết.

## Quy ước Thư viện (Research Storage Conventions)

1. **Naming**: Đặt tên file có tiền tố (`arch_`, `tech_`, `evol_`, `sec_`).
2. **YAML Frontmatter**: Phải có metadata (title, date, author_persona, mission_id, node_type, inbound_edge, tags, status) ở đầu mỗi file.
3. **Indexing**: Mọi báo cáo mới phải được chèn link vào danh sách bên dưới.
